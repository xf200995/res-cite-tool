工具使用说明
注：本工具在 CocosCreator v2.4.15 环境开发，理论适用 v2.4.x 版本，v2.x 其它版本需验证有效再使用，不适用 v3.x 版本。

一、快速上手

  1. 在资源管理器中选中要查询的资源（支持多选）。
  2. 按快捷键（默认 Shift+F12，可在“快捷键”中修改），或点击面板右上角“查询”。
  3. 结果会按“引用该资源的文件”分组显示，点击结果行即可在资源管理器中定位。
  4. 点击行内“引用节点”，可展开该文件中引用此资源的具体节点（节点路径 · 组件.属性）。

二、按钮说明

  • 查询：按资源管理器当前选中的资源重新查询引用。
  • 重建索引：丢弃现有索引并全量重建；正常使用无需点击，适用场景见第四节。
  • 快捷键：展开快捷键设置；点击输入框后按下组合键，再点“保存”生效，“默认”可恢复 Shift+F12。
  • 当前选中（路径）：点击面板顶部的资源路径，可在资源管理器中定位该资源。
  • 分组标题行：点击“资源路径 / N 个引用”所在行，可在资源管理器中定位并选中该资源（多选查询时可逐个定位）。
  • 查看引用 / 折叠引用（分组标题）：位于每组“N 个引用”右侧；单次选中多个资源时所有分组默认折叠，点击可展开或折叠该资源的所有引用资源列表（单选时默认展开）。
  • 展开全部引用 / 折叠全部引用：位于索引状态行最右侧，一次性展开或折叠所有选中资源的引用资源列表；展开时不会展开引用行内的节点列表。
  • 查看引用 / 折叠引用（引用行）：位于每个引用资源行内，展开/收起该文件中引用此资源的具体节点列表（节点路径 · 组件.属性），展开后按钮高亮。点击节点行会自动打开该 prefab 的预制体编辑模式，并在层级管理器中选中对应节点。
  • 显示：在操作系统文件夹中打开被引用的资源文件。
  • 结果行：点击整行可在资源管理器选中并高亮该引用资源。
  • 工具使用说明：打开本说明页面。

三、查找范围

  • 数据来源为编辑器导入产物 library/imports 中的序列化资源，覆盖预制体、场景、动画、材质、JSON、图集等对资源的 UUID 引用。
  • 图片等“主资源 + 子资源”按资源家族聚合，选中贴图也能查到对 spriteFrame 的引用。
  • 脚本引用：组件挂载脚本时记录的压缩 UUID（兼容 22 / 23 字符两种格式）。
  • 位图字体（.fnt）的 textureUuid 也会计入。
  • 不包含：代码中通过路径加载（如 loadRes('resources/xxx')）、粒子 plist 中按文件名引用的贴图，以及间接（递归）引用链。

四、什么时候需要“重建索引”

  • 正常不需要：每次查询都会自动检测资源变化并增量刷新，只重读变动资源。
  • 仅建议在这些情况手动重建：怀疑索引异常或结果明显与项目不符；手动改动/删除了缓存文件；从版本控制或其他途径整体替换了资源与 library 目录；切换分支后首次查询结果异常。
  • 编辑器版本或缓存版本变化时插件会自动全量重建，无需手动点击。

五、使用事项

  • 插件加载后会在后台构建索引，首次可在状态栏看到构建进度；构建期间查询会等待完成。
  • 缓存位置：local/res-cite-tool/index-cache.json，删除后下次查询会自动全量重建。
  • 快捷键在 Creator 窗口内生效；命中时会拦截编辑器同组合键，若与常用快捷键冲突请在“快捷键”中改键。
  • “查看引用 / 折叠引用（引用行）”为按需解析该文件，若资源正在导入可能提示稍后重试；嵌套预制体内部的节点会在其自身资源条目下展开。
  • 点击节点行定位 prefab 节点时，场景面板会切换到预制体编辑模式；若当前场景有未保存修改，请先保存再定位。
  • 结果仅统计“被其他资源引用”，自引用与同一资源内部的子资源引用已自动过滤。
  • 万级资源项目首次全量构建约 1–3 秒，之后查询为毫秒级。
