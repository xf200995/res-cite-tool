# res-cite-tool · Cocos Creator 资源引用工具

面向 **Cocos Creator 2.4.x** 的编辑器扩展，提供两个 Dockable 面板：

- **资源引用查找**：选中资源后，查出「谁在引用它」，并可直接定位到引用资源，乃至预制体里的具体节点。
- **资源引用管理**：按检索范围扫描「未被引用的资源」，支持批量勾选与清理（同时删除 `.meta`）。

引用数据来自编辑器导入产物 `library/imports` 中的序列化 JSON，不依赖运行时，也不修改项目资源（清理操作除外）。

> 本项目在 Cocos Creator v2.4.15 下开发，理论适用 2.4.x；其他 2.x 版本需自行验证，**不适用 3.x**。

## 功能

### 资源引用查找

- 支持多选资源，按“被哪些资源引用”分组展示，点击结果行可在资源管理器中定位。
- 展开引用行可查看具体节点（`节点路径 · 组件.属性`），点击节点会进入该预制体的编辑模式并在层级管理器中选中节点。
- 覆盖序列化引用：预制体、场景、动画、材质、JSON、图集等对 UUID 的引用；图片等「主资源 + 子资源」按资源家族聚合。
- 脚本组件挂载记录使用压缩 UUID（兼容 22 / 23 字符两种格式）；位图字体 `.fnt` 的 `textureUuid` 也会计入。
- 首次在后台构建索引，之后每次查询自动检测资源变化并增量刷新；万级资源项目首次全量构建约 1–3 秒，之后查询为毫秒级。
- 提供「重建索引」，仅在怀疑结果异常、手改缓存、整体替换 `library` 或切分支后使用。

### 资源引用管理（未引用资源清理）

三种检索范围：

1. **忽略清理目录**：检索 `assets` 下除指定目录以外的资源，多个目录用中/英文逗号分隔，路径相对 `assets`。
2. **指定清理目录**：通过目录选择器指定 `assets` 内的某个目录，仅检索该目录。
3. **resources 引用资源查询**：检索 `assets/resources` 下被其他资源引用的所选类型资源，并按「资源引用查找」的列表格式展示引用来源。

其他能力：

- 按文件类型勾选参与检索的资源；`.meta` 默认排除，「全部」可一键全选/取消。
- 未引用判定带保护规则：同目录同名 `.plist` 图集包含的 png、Spine（`.skel` / `.atlas`）与 DragonBones（`.json` / `.dbbin`）容器包含的贴图不单列；骨骼动画按「资源组」整体判定与清理；自动图集 `.pac` 在其目录及子目录仍存在纹理资源时视为在用。
- 「全选资源」「清理资源」：清理会删除资源文件及其 `.meta`，操作前弹出确认框，且**无法撤销**，建议在版本控制下使用。
- 检索范围、指定目录、文件类型勾选会自动保存，下次启动恢复。
- 面板自带「工具使用说明」，规则细节以内置说明为准。

## 安装

1. 将整个 `res-cite-tool` 目录放入以下任一位置：
   - 项目级：`<你的 Cocos Creator 项目>/packages/res-cite-tool`
   - 全局：`%USERPROFILE%\.CocosCreator\packages\res-cite-tool`（macOS 为 `~/.CocosCreator/packages/res-cite-tool`）
2. 重启（或重新加载）Cocos Creator。
3. 菜单栏「扩展 → 资源引用工具」下会出现两个入口：
   - 「资源引用查找」→ 主面板
   - 「资源引用管理」→ 未引用资源清理面板

> 扩展需在项目打开状态下使用：索引依赖项目的 `library/imports`，未打开项目时查询会返回索引不可用。

## 使用步骤

### 查找引用

1. 在资源管理器中选中一个或多个资源。
2. 按快捷键（默认 `Shift+F12`），或点击面板右上角「查询」。
3. 结果按「引用该资源的文件」分组；点击行可定位资源，点击「查看引用」可展开节点明细。
4. 需要改键时点击「快捷键」，在输入框按下组合键后「保存」；「默认」恢复 `Shift+F12`。快捷键仅在 Creator 窗口内生效，命中时会拦截编辑器同组合键。

### 清理未引用资源

1. 选择检索范围（忽略目录 / 指定目录 / resources 引用查询）。
2. 勾选文件类型，点击「开始查找」。
3. 在结果列表中勾选要清理的资源（点击整行只是定位，勾选需点左侧复选框；骨骼组按整组处理）。
4. 点击「清理资源」，确认后删除文件与 `.meta`。

## 目录结构

```
res-cite-tool/
├── package.json          # 扩展清单：菜单、两个面板（panel / panel.unused）定义
├── main.js               # 扩展主进程入口：索引生命周期、快捷键、文件操作、IPC 消息
├── lib/
│   ├── indexer.js        # 引用索引：全量/增量构建、缓存、查询、未引用扫描、骨骼组与自动图集保护
│   ├── extract.js        # 从 library/imports 序列化文本提取 UUID 引用（完整/压缩 UUID、__type__）
│   ├── uuid.js           # 22 / 23 字符压缩 UUID 解码
│   ├── settings.js       # 快捷键规范化、匹配、读写
│   └── scan-assets.js    # 扫描 assets 目录，返回子目录与文件后缀类型
└── panel/
    ├── index.js          # 资源引用查找面板逻辑
    ├── template.html     # 主面板结构（含内置使用说明）
    ├── style.css         # 主面板样式
    ├── unused.js         # 资源引用管理面板逻辑
    ├── unused.html       # 管理面板结构（含内置使用说明）
    └── unused.css        # 管理面板样式
```

运行时数据写在**项目**的 `local/res-cite-tool/` 下（不属于本仓库）：

- `settings.json`：快捷键配置
- `unused-settings.json`：检索范围与文件类型勾选
- `index-cache.json`：引用索引缓存，删除后下次查询自动全量重建

## 扩展消息（IPC）

面板 → 主进程（均以 `res-cite-tool:` 前缀发送）：

| 消息 | 作用 |
| --- | --- |
| `open-panel` / `open-unused-panel` | 打开对应面板（菜单入口） |
| `panel-ready` | 面板就绪，补发待处理的触发请求 |
| `query` | 按 UUID 查询引用 |
| `query-nodes` | 查询某引用文件内引用目标资源的具体节点 |
| `find-unused` | 扫描未引用资源 |
| `find-resource-refs` | 扫描 `resources` 下被引用的资源及来源 |
| `delete-assets` | 删除指定资源（含确认框） |
| `pick-directory` | 选择 `assets` 内的目录 |
| `list-meta` | 列出 `assets` 子目录与文件类型 |
| `get-unused-settings` / `set-unused-settings` | 读取/保存检索配置 |
| `get-settings` / `set-shortcut` | 读取/保存快捷键 |
| `get-status` / `rebuild-index` | 索引状态与手动重建 |

主进程 → 面板：`trigger`（打开并携带当前选中资源）、`progress`（索引构建进度）。

## 已知限制

- **仅覆盖序列化引用**。不包含：代码中按路径加载（如 `loadRes('resources/xxx')`）、`require`、构建配置（如启动场景）、粒子 plist 中按文件名引用的贴图，以及间接（递归）引用链。
- 仅统计 `assets` 下的资源；`db://internal` 内置资源不参与未引用候选。
- 单个导入文件超过 4 MB 时跳过解析，其引用不会被计入。
- `resources` 目录资源常被代码动态加载，建议在「忽略清理目录」中加入，避免误判后清理。
- 清理直接删除资源与 `.meta`，不可撤销，也不进入系统回收站。
- 扩展需要项目已打开且 `library/imports` 就绪；启动阶段会等待导入产物，超时后索引不可用（重新打开项目即可恢复）。
- 结果只统计「被其他资源引用」，自引用与同一资源内部的子资源引用会被过滤。
